# Purdue Esports Broadcast Operations Guide

Jekyll site (GitHub Pages) documenting setup, operation, and teardown of the Purdue Esports casting set and its studio integration.

- `index.html` — page content (uses `_layouts/esports.html`)
- `_data/esports/*.yml` — equipment, signal flow, setup, games, events, teardown, troubleshooting

Preview locally: `bundle install && bundle exec jekyll serve`
